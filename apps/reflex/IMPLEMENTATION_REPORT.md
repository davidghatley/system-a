## INFERRED

- Fixed-environment demonstrations should be stable because inference uses evaluation mode and no sampling. Small cross-hardware/library floating-point differences remain possible.
- The observed unsafe-looking disagreement demonstrates why the artifact is useful for observability and evaluation, but also why its output must not directly authorize interventions.

## UNKNOWN

- Calibration, accuracy, and decision utility on representative System-A agent states have not been measured. The checkpoint's training-domain coverage for this state format is unknown.
- CPU latency, fresh-download duration, and behavior with very long/truncated production states were not measured in this iteration.
- Bitwise reproducibility across hardware, drivers, and dependency versions is not established; the lock only constrains the tested software versions.

## RECOMMENDED

- Treat probabilities as advisory telemetry and gate any consequential action with independently tested deterministic controls.
- Before operational use, define a trajectory-disjoint evaluation set and measure per-question accuracy/calibration, especially for unsafe false-positive interventions.
- Have an independent verifier execute the README path in a fresh environment and review the pinned source/checkpoint trust boundary.
